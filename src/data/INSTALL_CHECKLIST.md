# Static Data Checklist

1. Keep new collection media in `public/media/collections/`.
2. Keep the five active category folders: `special-one`, `wedding-invitations`, `certificate-folders`, `gifts-and-favours`, and `corporate-official`.
3. Use `/media/collections/...` in website data, never `/public/media/collections/...`.
4. Run `npm run typecheck`.
5. Run `npm run lint`.
6. Run `npm run smoke`.
7. Run `npm run build`.
8. Review video-only folders manually, because the current collection UI renders image galleries.
